# WellQueue User Mobile Application

**WellQueue** is a modern, human-centric clinical care and virtual queue management application built using Flutter and Material 3 design principles based on Stitch design specifications.

## 🚀 Features

- **Authentication & Security**: Modern sign in with email/password, biometrics, Google login, and HIPAA/SOC2 compliance footers.
- **Account Registration**: Seamless onboarding flow for new patient accounts.
- **Find Clinics**: Interactive location search, specialty filtering (Urgent Care, Pediatrics, General Care, Dental), wait-time status, and clinic details.
- **Clinic Details**: Real-time virtual wait estimations, specialist profiles, appointment booking, and clinic information.
- **My Health & Queues**: Real-time virtual queue position tracking (e.g. 4th in line), QR code check-in, estimated arrival times, and complete past queue history.

## 🎨 Design System

- **Primary Color**: `#00478D` (Clinical Trust Blue)
- **Secondary Color**: `#006970` (Calming Teal Accent)
- **Background**: `#F8F9FF` (Soft Medical White)
- **Typography**: `Manrope` (Headlines) & `Inter` (Body & Labels)
